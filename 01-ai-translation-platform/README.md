# AI 翻译平台接口工程化与稳定批处理

> 项目状态：阶段 1 已完成本地开发与审核。当前版本具备工程骨架、命令行参数校验、不可变配置和运行数据模型，尚未接入真实翻译请求。

## 项目定位

面向通用 Web AI 翻译平台的接口分析与工程化实践，目标是将动态参数、会话请求、流式响应解析和批量任务处理拆分为可维护、可测试的组件。

## 计划范围

- 动态参数和签名流程的可重复验证。
- 基于 `requests.Session` 的连接复用、超时、有限重试和错误分类。
- 流式响应事件解析与异常响应处理。
- 低负载请求节奏、可选网络出口和有限故障切换。
- CSV/XLSX 批量输入、去重缓存、断点续跑和原子导出。
- 结构化运行摘要、离线测试和脱敏公开样例。

以上未落地能力仍是后续开发目标，不代表当前版本已经完成真实接口或批处理验收。

## 当前能力

- 使用 `translate` 与 `batch` 子命令校验单条和批量任务参数。
- 仅允许 `en` 与 `zh-CHS` 双向组合，拒绝空文本、同语言及越界数值。
- 校验 CSV/XLSX 文件、输入列和项目根目录相对路径，防止输出覆盖输入。
- 提供不可变低负载配置及 `TranslationResult`、`FailureRecord`、`RunSummary` 数据模型。
- 28 项离线测试覆盖工程入口、路径、CLI、配置和数据模型。

当前命令只负责参数解析与校验，不会发起网络请求，也不构成“当前接口可调用”的证据。

## 证据与安全边界

- 不公开 Cookie、账号 Token、代理地址、认证信息或真实业务数据。
- 历史记录、离线合成验证和当前接口验证分别统计，不混用结果口径。
- 公开样例只使用人工构造或明确脱敏的数据。
- 私有输入、完整日志、原始响应和内部开发计划不进入公开仓库。

## 后续交付

后续阶段将按审核批次提交动态参数、请求客户端、流式响应解析、稳定性机制、批处理管线和脱敏验证证据。
